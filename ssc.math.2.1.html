// DEFINITIONS

মূল সংজ্ঞাসমূহ

প্রতিটি সংজ্ঞা তালিকা পদ্ধতি ও সেট গঠন পদ্ধতি উভয়ভাবে উপস্থাপন করা হয়েছে।

DEF · 01
সেট
সুনির্দিষ্ট ও সুপরিচিত বস্তুর সংগ্রহকে সেট বলে। প্রতিটি উপাদানকে সদস্য বলা হয়।
▸ তালিকা পদ্ধতি A = {2, 4, 6, 8, 10}
▸ সেট গঠন পদ্ধতি A = {x : x জোড়, 1 ≤ x ≤ 10}
DEF · 02
উপসেট
A-এর প্রতিটি উপাদান যদি B-তেও থাকে, তাহলে A হলো B-এর উপসেট। চিহ্ন: A ⊆ B
▸ উদাহরণ A = {1, 3, 5}, B = {1, 2, 3, 4, 5}
∴ A ⊆ B ✓
▸ সেট গঠন পদ্ধতি A = {x : x ∈ B, x বিজোড়}
DEF · 03
শক্তি সেট
A-এর সকল উপসেট নিয়ে গঠিত সেটকে শক্তি সেট বলে। |A|=n হলে |P(A)| = 2ⁿ
▸ উদাহরণ (A = {1,2}) P(A) = {∅, {1}, {2}, {1,2}}
|P(A)| = 2² = 4
▸ সেট গঠন পদ্ধতি P(A) = {B : B ⊆ A}
DEF · 04
কার্তেসীয় গুণজ
A ও B-এর সকল ক্রমজোড় (a, b) নিয়ে গঠিত সেটকে কার্তেসীয় গুণজ বলে। চিহ্ন: A × B
▸ উদাহরণ A={1,2}, B={a,b}
A×B = {(1,a),(1,b),(2,a),(2,b)}
▸ সেট গঠন পদ্ধতি A×B = {(x,y) : x∈A, y∈B}
DEF · 05
মিলন সেট (Union)
A ও B-এর সকল উপাদান নিয়ে গঠিত সেটকে মিলন সেট বলে। চিহ্ন: A ∪ B
▸ উদাহরণ A={1,2,3}, B={3,4,5}
A∪B = {1,2,3,4,5}
▸ সেট গঠন পদ্ধতি A∪B = {x : x∈A অথবা x∈B}
DEF · 06
ছেদ সেট (Intersection)
A ও B-এর সাধারণ উপাদান নিয়ে গঠিত সেটকে ছেদ সেট বলে। চিহ্ন: A ∩ B
▸ উদাহরণ A={1,2,3,4}, B={3,4,5,6}
A∩B = {3,4}
▸ সেট গঠন পদ্ধতি A∩B = {x : x∈A এবং x∈B}
// GEOMETRIC EXAMPLES

জ্যামিতিক উদাহরণ

জ্যামিতিক আকৃতি ব্যবহার করে সেটের ধারণা বোঝা যাক।

ত্রিভুজের বিন্দু ও বাহুর সেট
একটি ত্রিভুজ ABC-তে শীর্ষবিন্দু, বাহু ও মধ্যবিন্দুগুলো আলাদা আলাদা সেট হিসেবে প্রকাশ করা যায়।
▸ শীর্ষবিন্দুর সেট (তালিকা পদ্ধতি)
V = {A, B, C}
▸ মধ্যবিন্দুর সেট
M = {D, E, F}
// D=মধ্যবিন্দু AB, E=মধ্যবিন্দু AC, F=মধ্যবিন্দু BC
▸ সেট গঠন পদ্ধতি
V = {x : x ত্রিভুজ ABC-এর শীর্ষবিন্দু}
M = {x : x কোনো বাহুর মধ্যবিন্দু}
|V| = 3 |M| = 3 V ∩ M = ∅ |P(V)| = 2³ = 8
বৃত্তের বিন্দুর সেট
একটি বৃত্তের উপরের সকল বিন্দু, ব্যাসার্ধ রেখাংশ ইত্যাদি সেট আকারে লেখা যায়।
▸ বৃত্তের উপরের বিন্দুর সেট
C = {P₁, P₂, P₃, P₄, ...}
// অসীম সেট (infinite set)
▸ সেট গঠন পদ্ধতি
C = {(x,y) : x²+y² = r²}
P = {P : |OP| = r, P ∈ সমতল}
▸ অভ্যন্তরীণ বিন্দুর সেট
I = {(x,y) : x²+y² < r²}
|C| = ∞ (অসীম সেট) C ∩ I = ∅ C ∪ I = বদ্ধ চাকতি
ষড়ভুজের শীর্ষবিন্দুর সেট
একটি নিয়মিত ষড়ভুজের শীর্ষবিন্দু, বাহু ও কর্ণ আলাদা সেট হিসেবে প্রকাশ করা যায়।
▸ শীর্ষবিন্দুর সেট
V = {A₁, A₂, A₃, A₄, A₅, A₆}
▸ সেট গঠন পদ্ধতি
V = {Aᵢ : i ∈ ℕ, 1 ≤ i ≤ 6}
D = {x : x ষড়ভুজের কর্ণ}
▸ বাহুর সেট
S = {A₁A₂, A₂A₃, A₃A₄, A₄A₅, A₅A₆, A₆A₁}
|V| = 6 |S| = 6 |D| = 9 (কর্ণ) |P(V)| = 2⁶ = 64
কোণের সেট
বিভিন্ন ধরনের কোণ (সূক্ষ্মকোণ, সমকোণ, স্থূলকোণ) আলাদা সেট গঠন করে।
▸ সূক্ষ্মকোণের সেট
A = {θ : 0° < θ < 90°}
▸ সমকোণের সেট
R = {θ : θ = 90°}
// এক উপাদানের সেট (singleton)
▸ স্থূলকোণের সেট
O = {θ : 90° < θ < 180°}
A ∩ R = ∅ R ∩ O = ∅ A ∩ O = ∅ বিচ্ছিন্ন সেট
স্থানাঙ্ক তলের বিন্দুর সেট
কার্তেসীয় স্থানাঙ্ক তলের বিন্দুগুলো ক্রমজোড় (x, y) হিসেবে প্রকাশিত হয় এবং এগুলো ℝ × ℝ = ℝ² সেটের উপাদান।
▸ ক্রমজোড় হিসেবে বিন্দুর সেট
S = {P, Q, R, T} = {(2,1),(4,2),(-1,-2),(-3,-4)}
▸ সেট গঠন পদ্ধতি (প্রথম পাদ)
Q₁ = {(x,y) : x > 0 এবং y > 0}
▸ কার্তেসীয় গুণজ
ℝ² = ℝ × ℝ = {(x,y) : x,y ∈ ℝ}
বিন্দু = ক্রমজোড় |ℝ²| = অসীম ৪টি পাদ = ৪টি সেট

// CARTESIAN PRODUCT

কার্তেসীয় গুণজ — বিস্তারিত

A × B মানে A ও B-এর সকল সম্ভাব্য ক্রমজোড়ের সেট।

উদাহরণ ১ — বিন্দু সেট

A = {1, 2} এবং B = {a, b, c}
A × B = {
  (1,a), (1,b), (1,c),
  (2,a), (2,b), (2,c)
}
|A×B| = 2 × 3 = 6

উদাহরণ ২ — জ্যামিতিক বিন্দু

x-স্থানাঙ্ক সেট × y-স্থানাঙ্ক সেট
X = {0, 1}, Y = {0, 1}
X×Y = {(0,0),(0,1),(1,0),(1,1)}
// একক বর্গের ৪ শীর্ষ

উদাহরণ ৩ — ত্রিভুজ শীর্ষ

V = {A, B, C} হলে V × V
V×V = {(A,A),(A,B),(A,C),
       (B,A),(B,B),(B,C),
       (C,A),(C,B),(C,C)}
|V×V| = 3² = 9
// FORMULAE

গুরুত্বপূর্ণ সূত্রাবলী

সেট অপারেশন সেট গঠন পদ্ধতি উদাহরণ
মিলন (Union) A ∪ B = {x : x∈A ∨ x∈B} {1,2}∪{2,3} = {1,2,3}
ছেদ (Intersection) A ∩ B = {x : x∈A ∧ x∈B} {1,2}∩{2,3} = {2}
পার্থক্য (Difference) A − B = {x : x∈A ∧ x∉B} {1,2,3}−{2} = {1,3}
পূরক (Complement) A' = {x : x∈U ∧ x∉A} U={1..5},A={1,2} → A'={3,4,5}
কার্তেসীয় গুণজ A×B = {(x,y) : x∈A, y∈B} |A×B| = |A|·|B|
শক্তি সেট P(A) = {B : B ⊆ A} |P(A)| = 2^|A|
অন্তর্ভুক্তি-বর্জন |A∪B| = |A|+|B|−|A∩B| De Morgan's Law প্রযোজ্য
